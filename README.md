# notepadpro
NotepadX Pro 2.0 es un editor de código avanzado desarrollado en Python con PyQt6 y QScintilla, diseñado para programadores que necesitan una herramienta ligera pero potente sin renunciar a las características de un IDE completo.
NotepadX Pro 2.0 es un editor de código avanzado desarrollado en Python con PyQt6 y QScintilla, diseñado para programadores que necesitan una herramienta ligera pero potente sin renunciar a las características de un IDE completo.

Características principales

Syntax highlighting para 15+ lenguajes: Python, JavaScript, TypeScript, HTML, CSS, C/C++, SQL, Bash, XML y más, con detección automática por extensión de archivo.
Explorador de archivos integrado en la barra lateral para navegar y abrir archivos directamente desde el editor.
Minimap para visión general del archivo y navegación rápida.
Terminal integrada con soporte para cualquier comando del sistema, sin salir del editor.
Paleta de comandos (Ctrl+Shift+P) al estilo VSCode para acceder a cualquier función sin tocar el ratón.
Búsqueda y reemplazo avanzada con soporte para expresiones regulares, distinción de mayúsculas y búsqueda por palabra completa.
Integración con Git: rama activa, estado de cambios, diff y log directamente desde el menú.
Pestañas múltiples con indicador de cambios sin guardar (●) y confirmación al cerrar.
Code folding, bracket matching, guías de indentación y columna límite a 100 caracteres.
Atajos de teclado para duplicar línea, mover línea, comentar/descomentar, zoom y word wrap.
Autosave cada 30 segundos para archivos ya guardados.
Tema Catppuccin Mocha con fuente JetBrains Mono.


Requisitos
Python 3.10+ · PyQt6 · PyQt6-QScintilla
